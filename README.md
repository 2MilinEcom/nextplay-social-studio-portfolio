# NextPlay Social Studio

Video editing and social content workspace with caption preparation, approval, scheduling, and publishing adapters.

## Technology

Python, SQLite, FFmpeg, JavaScript.

## Run locally

Use Python 3.11 or later. Create a virtual environment, install `source/requirements-platform.txt`, then run `python -m social_platform.server --port 8770` from `source/`. Open `http://127.0.0.1:8770`. FFmpeg is needed for video processing. See `README_SOCIAL_STUDIO.md` for optional integrations and feature limitations.
